# Connexio RC1 — travail en cours

- suppression des scripts et workflows temporaires ;
- CI TypeScript, tests, audit responsive et audit produit verts ;
- configuration native iOS/Android vérifiée ;
- build EAS preview installé sur appareils physiques ;
- validation backend, APNs/FCM et TURN sur préproduction.
