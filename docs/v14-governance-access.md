# Connexio V14 — gouvernance, accès et médias

Cette passe formalise les règles produit suivantes :

- les Visionnaires administrent tous les groupes ;
- les responsables de groupe sont des Amiraux ou Capitaines désignés ;
- le groupe Annonce est en lecture seule pour les membres, avec publication réservée aux Visionnaires et aux éditeurs autorisés ;
- les automatisations de messages sont accessibles aux Visionnaires et responsables du groupe ;
- les comptes Free peuvent recevoir des invitations, conversations et appels, mais ne peuvent pas les initier ;
- les comptes Free ne publient que des Besoins et doivent passer Triton pour les autres publications ou pour rejoindre un groupe ;
- les médias compatibles sont consultables dans l’application ;
- les contours et badges de statut utilisent le code couleur Neptune ;
- les sons Connexio fournis sont utilisés pour les appels et notifications.
